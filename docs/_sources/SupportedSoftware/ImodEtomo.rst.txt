Imod and Etomo
===============

Etomo tutorial:`Etomo tutorial <https://bio3d.colorado.edu/imod/doc/etomoTutorial.html>`_.

Using etomo on the cluster:

1. Login to Open OnDemand
2. Go to Interactive Apps > Desktop Access and create a desktop session 
3. When the desktop session starts, click Launch Desktop Access
4. In the desktop session choose the terminal icon from the bottom of the desktop
5. In the terminal window type: etomo
